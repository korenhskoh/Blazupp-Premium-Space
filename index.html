    Booking reminders

    Auto-remind before each session. The admin always gets it; a customer only if you tick 🔔 on their booking (Bookings tab), or if you turn on remind-all below.

    These are set here in the app (no redeploy needed). The service reads them each cycle. The values below still need to exist on Railway once to switch the engine on:

    REMINDER_ENABLED=true
    REMINDER_LEAD_HOURS=24
    REMINDER_ADMIN_PHONE=+60…
    REMINDER_ADMIN_EMAIL=you@gmail.com
    REMINDER_ALL_CUSTOMERS=false ← true = remind EVERY customer
    REMINDER_KEY=a long secret
    SUPABASE_URL=…  SUPABASE_ANON_KEY=…

    The REMINDER_KEY must also be saved in Supabase (run the reminder SQL, then set the key once). Whatever's connected — WhatsApp, Gmail, or both — is used automatically.

    REMINDER_ALL_CUSTOMERS=true reminds every customer automatically — the per-booking 🔔 is then ignored (everyone gets it). Leave it false to control it per booking with the 🔔 tick.
